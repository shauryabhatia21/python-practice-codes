# Python Practice Codes

A topic-wise organized suite of Python exercises, scripts, and practice projects covering fundamentals to data science.

## 📁 Topic Directory

- **`01_Basics_and_Loops/`**: While & for loops, prime numbers, armstrong numbers, factorials, digit sums, number generators, binary-to-decimal & decimal-to-binary converters.
- **`02_Strings/`**: String methods, palindrome verification, case conversions, partitioning, and slicing.
- **`03_Data_Handling_and_Files/`**: File I/O operations, Pickle serialization, Excel/CSV handling, SQL notes, and SMS/Email messaging modules.
- **`04_Data_and_Pandas/`**: Pandas DataFrames, CRUD data operations, and Library issue/return management.
- **`05_OOP_and_Inheritance/`**: Classes & objects, banking system, single & multilevel inheritance, inner classes.
- **`06_Exception_Handling/`**: Custom exceptions, `try-except-finally` patterns, defensive coding.
- **`07_GUI_Tkinter/`**: Desktop GUI applications (calculator, percentage calculator, SQL student interface).
- **`08_NumPy_and_Math/`**: Multi-dimensional array manipulations with NumPy and plotting with Matplotlib.
- **`09_Mini_Games/`**: 2D arcade games including Commando shooter, Racing game, and Shooting game.

## 🚀 Running the Code
Run any Python file directly using:
```bash
python filename.py
```
